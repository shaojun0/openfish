Usage

Install packages via pip:

pip install -i {{ base_url }}/simple/ <package-name>

Authentication is required. Create an API key from the dashboard, then set up ~/.netrc:

machine <host> login __token__ password <api-key>

Or add to requirements.txt:

--index-url {{ base_url }}/simple/
package-name==1.0.0

Upload

Upload packages using twine:

twine upload --repository-url {{ base_url }}/ --username __token__ --password <api-key> dist/*

Python Builds

Use as a uv Python install mirror:

# PowerShell
$env:UV_PYTHON_INSTALL_MIRROR = "{{ base_url }}/python-builds/"
uv python install 3.12

# Unix shell
export UV_PYTHON_INSTALL_MIRROR="{{ base_url }}/python-builds/"
uv python install 3.12
