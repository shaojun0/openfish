📖 How to Use

# pip install
pip install -i {{ base_url | replace('://', '://__token__:@') }}/simple/ <package>
#   Or configure ~/.netrc (Linux/macOS) / %HOME%\_netrc (Windows):
#     machine <HOST> login __token__ password <API_KEY>

# uv (recommended)
uv pip install --index-url {{ base_url | replace('://', '://__token__:@') }}/simple/ <package>

# twine upload
twine upload --repository-url {{ base_url }}/ \
  --username __token__ --password <API_KEY> dist/*

# curl test
curl -H "Authorization: Bearer <API_KEY>" {{ base_url }}/simple/
⚠️ Your deployment may use a private or self-signed CA certificate. Only follow these steps if you see SSL certificate verify failed errors.

⬇ Download CA Certificate (ca_chain.pem)

export REQUESTS_CA_BUNDLE=/path/to/ca_chain.pem

  --username __token__ --password <API_KEY> dist/*
